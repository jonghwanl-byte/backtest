# TAA 전략 검증 프레임워크

기존 `Hybrid-Hysteresis-TAA` 백테스트에서 지적된 문제들을 **숫자로 판정**하기 위한 도구입니다.
"내 전략이 좋다"를 증명하는 게 아니라, **"내 전략이 과최적화가 아님을 반증할 수 없는지"** 를 검사합니다.

```bash
pip install yfinance pandas numpy scipy openpyxl tabulate
python run_study.py                 # 전체 (10~30분)
python run_study.py --quick         # 격자 축소, 2~3분
python run_study.py --synthetic     # 네트워크 없이 엔진 동작 확인
```

결과: `out/report.md` (읽는 용), `out/results.xlsx` (시트별 표), `out/grid_full.csv` (원자료)

## 원본 코드 대비 수정한 것

### 치명적

**1. 워밍업 부족 → 신호 오류.** 원본은 `period="400d"`(≈276거래일)에 200일 MA를 쓰고 상태를
`0.0`으로 초기화합니다. 히스테리시스는 경로 의존적이므로, 실제로는 예전에 +3%를 뚫고 ON을
유지 중인 자산이 **OFF로 계산**됩니다. 매일 워밍업 시작점이 밀려 어제/오늘 결과가 뒤집히고
유령 신호가 발생합니다. → 여기서는 전체 히스토리로 워밍업 후 평가 구간만 잘라냅니다.

**2. 룩어헤드.** T일 종가 신호를 T일 수익에 적용하면 실현 불가능한 성과가 나옵니다.
`ExecConfig.exec_lag` 로 명시 제어하며 **기본값 1**(익일 종가 체결)입니다.
검증1이 이 차이를 직접 보여줍니다.

**3. `Adj Close` 폴백.** 최신 yfinance는 `auto_adjust=True`가 기본이라 `Adj Close`가 없습니다.
원본의 폴백은 라이브러리 버전에 따라 조용히 미조정 가격으로 전환될 수 있습니다.
(TLT는 월배당이 커서 신호가 달라짐) → `auto_adjust=True` 명시.

### 중요

- **현금 수익률**: flat 2% → `^IRX` 실측. 2015–2021 저금리기 과대평가 제거.
- **세금**: 해외주식 양도세 22%(연 250만원 공제, 익년 5월 납부)를 이동평균 취득단가로 실제 추적.
- **리밸런싱**: "매일 목표비중 복귀"는 비용을 과대계상. 신호 변경 + 드리프트 허용치 방식이 기본.
- **정수주 옵션**: 소액계좌에서 2.5%p 비중 변경이 1주 미만이라 체결 불가한 문제 재현.
- **데이터 검증**: 티커 누락, 데이터 낡음, ±35% 이상치 탐지 + 재시도.

## 케이스 수 관리

밴드 격자 K개일 때:

| 모드 | 케이스 수 (K=56) | 용도 |
|---|---|---|
| `--grid-mode linked` | K × 시나리오 × 룰 = 1,120 | 세 자산 동일 밴드 |
| `--grid-mode qqq` (기본) | K × 20 = 1,120 | QQQ만 격자 (TLT/GLD는 영향 미미) |
| `--grid-mode full` | K³ × 20 = 3,512,320 | 전조합 (오래 걸림) |

**성능**: 자산별 신호를 캐시하고 포트폴리오 수익률을 선형결합으로 분해하므로
17만 케이스가 약 75초입니다. 파라미터 조합이 K³여도 신호는 3K개만 계산합니다.

```
ret_t = rf_t + Σ_a bw_a · S_a[t] · (r_a,t − rf_t) − c · Σ_a bw_a · |ΔS_a[t]|
```

**주의**: 격자 스캐너는 "매일 리밸런싱 + 세금 미반영" 근사입니다 (엔진과 상관 0.98).
최종 후보는 반드시 `--stage live`의 전수 시뮬레이션으로 재검증하세요.

## 해석 가이드

**케이스가 많을수록 1등은 의미가 없어집니다.** 17만 개를 돌리면 순수 노이즈에서도
샤프 0.28짜리 "최적 조합"이 나옵니다 (합성 랜덤워크로 실측). Deflated Sharpe가
이걸 걸러냅니다.

**보아야 할 순서:**

1. 검증1에서 `exec_lag=-1`만 좋다 → 원본 백테스트 숫자를 전부 폐기하세요.
2. 검증3b에서 `max − median > 0.15` → 1등 조합은 우연입니다. 중앙값을 기대치로 삼으세요.
3. 검증4의 워크포워드 CAGR/MDD → **이것이 실전에서 기대할 수 있는 유일하게 정직한 숫자**입니다.
4. 검증6a에서 `QQQ 200MA 단순필터`와 차이가 작다 → 파라미터 15개를 유지할 이유가 없습니다.

## 구조

```
taa/
  config.py    전략/체결/격자 설정 (dataclass)
  data.py      다운로드·검증·캐시, 합성 데이터
  signals.py   히스테리시스 상태기계 (벡터화), 스칼라 캐시
  fastscan.py  대규모 격자 스캐너, 표면·이웃 견고성
  engine.py    전수 시뮬(주식수·취득단가·세금·정수주), 벤치마크
  metrics.py   성과지표, Deflated Sharpe, 변동성 정규화
  periods.py   레짐·IS/OOS·롤링·워크포워드 분할, 블록 부트스트랩
  study.py     검증 스위트
run_study.py   CLI
```
